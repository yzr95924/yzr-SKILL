# 改写承接

> 本文件承载[章节](../SKILL.md#step-6-改写承接确认后)的执行细节

用户显式说"直接改，不用审"时跳过 review，静默对照[规则清单](catalog.md)定位问题（不出结论）再按修法改；
说明一律以一句对原文的精简理解开头

## 执行约束

- **永不可砍**：事实 / 数据 / 结论 / 引用一克不少（拿不准的标"存疑请人工核对"）；
  caveats（"但 / 然而 / 前提是"引出的限定条件）；用户点名保留的内容；Markdown 结构
  （标题层级 / frontmatter / 代码块 / 链接 / 图片引用 / 表格 / 列表嵌套）原样不动
- **就地编辑保护**：文件被 git 跟踪就直接就地编辑，说明里提示"`git diff` 可核对 / 恢复"；
  不在版本控制下时，删掉的**整段原文**必须附在输出末尾"已删内容"块（不占说明额度），
  否则不许就地删，先贴原文再问用户

## 输出

1. 改写后的完整版本（文件输入就地编辑，粘贴输入在对话内输出全文）
2. 最多 3 行说明：每条改动引用 ≥ 1 个 catalog 规则名；存疑待核一条一行（不占说明额度）。说明比改写版
   还长时删说明

改写产物按[章节](../SKILL.md#执行原则)的自审合规口径机检，应清的命中清零后再交付
