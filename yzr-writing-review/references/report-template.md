# 文档审查报告模板（SSOT）

主表 6 列固定，严重度 4 级，不允许 agent 自创新列。

## 两档规则

- **轻量档**（默认）：头部 + 主表 + 一句话收尾。适用于日常单文档 review（发现通常
  ≤ 5 条）。
- **完整档**：轻量档内容 + 总结段 + 不报告项。适用于大范围体检（多文件 / 遗留文档）
  或用户明确要存档。

---

# Writing Review Report

**输入**: <文档描述 / 文件路径 / 审查范围>
**参照输入**: <有 — 列范围 / 无 — 只审文档内>
**语言 / 文体**: <识别到的语言 / 文体>
**Review 时间**: YYYY-MM-DD
**Reviewer**: <agent / 用户名>

## 发现项（主表）

| # | 位置（file:line / file:§小节） | 场景 / 卡片 | 严重度 | 问题 | 建议 |
| --- | --- | --- | --- | --- | --- |
| 1 | design.md §3 | Logic.L3 结论与论据脱节 | Blocker | 结论"方案 A 最优"与对比表矛盾 | 收窄结论或补论据 |
| 2 | design.md §2.1 | Structure.S2 同义重述段 | Major | 整段复述 §1 背景 | 删，保留 §1 那版 |
| 3 | ... | ... | ... | ... | ... |

每条规则:

- **位置**: 精确到 file:line 或 file:§小节（多文件 review 写 file:line-line）
- **场景 / 卡片**: 映射到 `catalog.md` 卡片名（含组前缀，如 "Structure.S2 同义重述段"）
- **严重度**: Blocker / Major / Minor / Nitpick — 判定查 `severity-rubric.md`
- **问题**: 一句话说明现象（不要泛泛"表述不佳"）
- **建议**: 一句话具体怎么做（不要泛泛"建议优化"）

**收尾**（轻量档必写，一句话）: <一句结论，如 "共 3 条发现，1 Blocker 2 Major，
建议先处理 §3 的结论与论据冲突。">

## 总结（仅完整档）

- **总发现项**: N
- **按严重度分布**: Blocker X / Major Y / Minor Z / Nitpick W
- **优先 top-3**:
  1. <最优先项 + 原因>
  2. ...
  3. ...
- **风险点**: <如有 — 对外发布 / 关键结论段 / SSOT 冲突等>
