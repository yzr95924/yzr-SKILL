# 严重度判定细则（SSOT）

4 级严重度，本文件是唯一权威定义。SKILL.md 和 report-template.md 都引用本文件，不重抄。

## Blocker

**定义**：逻辑上站不住 / 对外有风险 / 必须立即修正。

**判定标准**：

- 逻辑自相矛盾（前后结论打架，读者会得到两个相反的答案）
- 结论与论据冲突（对比表说 B 优，结论写 A 优）
- 跨文档事实冲突（SSOT 违规：与参照文档数据 / 结论矛盾）
- 事实表述存疑且影响结论成立（"数据 X 证明……"但 X 可能错）

**反例**（不该升 Blocker）：

- 仅是文笔问题 → Major / Minor

## Major

**定义**：明显问题，不修读者会被误导或读不下去。

**判定标准**：

- 整段冗余（离题段 / 同义重述段）
- 章节职责交叉 / 论证链断裂 / 主次颠倒
- 跨章节术语不一致 / 营销腔 / 成片 AI 腔（≥ 3 类指纹）
- 跨文档口径漂移（同一概念两处定义 / 术语用法不一致）

**反例**：

- 仅 1–2 个 AI 腔指纹 → Minor
- 仅句级冗余 → Minor

## Minor

**定义**：局部改进，值得做但非紧急。

**判定标准**：

- 句级冗余（同义重述句 / 填充句 / 过度限定词）
- 超长句 / 句式单调 / 连接词拐杖
- 注水开头结尾 / 信息放置错位 / 摘要与正文互注水
- 局部 AI 腔（1–2 类指纹）/ 谄媚 / 过度对冲 / 正式度失配

**反例**：

- 整段冗余 → Major

## Nitpick

**定义**：风格 / 语气 / 排版可选项。

**判定标准**：

- 人称混用 / 并列结构错位 / 名词化与空动词
- 层级碎片化 / 错别字 / 标点（机械可判定项，可并入"不报告项"）

**反例**：

- 误导性表述（注释 / 文字说 A 实际是 B）→ Major
- 术语不一致跨章节 → Major

## 升级 / 降级规则

- 对外发布 / 评审 / 汇报文档：Minor → Major，Major → Blocker
- 草稿 / 个人笔记 / 内部 scratch：整体降一级
- 结论支撑段（论证核心）里的问题**不降级**
- 单点 AI 腔指纹不升 Major（需成片才 Major）
