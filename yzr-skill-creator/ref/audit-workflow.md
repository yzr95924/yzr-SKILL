# 原则校验的完整流程

> 本文件承载[章节](../SKILL.md#原则校验)的执行细节

## 步骤

1. **机械项 + 参审文件清单**：`python -m tools.verify <skill-dir> --audit`（三型定义见 `assets/skill-template.md`）；
   输出含参与审计的 md 清单
2. **逐文件循环，只报不修**：一次只审一个文件、全量精读不抽样，对照判定清单中未标〔跨文件〕
   的条目逐条给结果词（口径见清单开头），证据 = 文件 + 原文引用；单文件过长时按节分批，一节一批
3. **跨文件判定**：清单中标〔跨文件〕的条目在此判：grep 现场取证 + 聚合步骤 2 的发现，逐条给结果词
4. **散文层转交**：本清单只管机制合规；md 散文质量转 yzr-writing-review、`tools/` 代码转 yzr-coding-review、
   `description` 触发质量转入口 3。转交给整个文件集，不只单文件（跨文件重复靠文件互为参照才查得出）；
   未处置不得收工
5. **报告只活在对话里**：不建 `audit-*.md` 归档文件（无人维护的第二真源）；报告分三小节：
   违反项（按清单 / 原则）、待删候选（按保留门槛，无则写"无"）、散文层（已转交 / 未转交 + 原因）；
   逐项等用户确认
6. **修复转入口 2**：先修跨文件级联项（如指标权威源）再修单文件项；修完 `verify` 复跑，
   evals 回归按判定清单"保留门槛"执行

> 用户要求"最严 / 仔细审查"时：正确性以验证证据为准（无证据不断言）；转入口 2 修复时只动仓库源

## 判定清单

机械项之后的逐条判定口径（脚本覆盖的项出候选与证据，是否违反照此判；结果词五档：通过 / 违反 / WARN / 标注 / 忽略）：

1. **agent 中立**：点名具体 agent（Claude Code / Qoder / Cursor 等）逐处复核：特有机制设计（该 agent 独有功能）通过；可泛化却写死判违反，改泛指
2. **触发语不回正文**：正文逐句问"管何时调还是怎么用"；何时调内容（触发语 / 路由结论）出现在正文判违反，触发负例归 `description`"不适用"槽；闸门 / 纪律句在执行点的重述不算
3. **指标单一来源**〔跨文件〕：同 skill 内同一 `<数字><单位>` 散落多文件判违反；定权威源，其余改常量名或指针引用；`eval/*.json` 断言里复述正文阈值不算散落（断言须可判定、无法改指针，权威源 = 正文，判忽略）
4. **机械操作归脚本**：按 [章节](../SKILL.md#执行原则) 的"机械操作归脚本"过每段文字，三型各判违反：
   零判断字节仍以文字承载（应脚本化）；md 重述脚本机制细节（机制挪脚本）；
   纯函数但不值脚本成本（判据见 [章节](create-workflow.md#第-3-步起草-skillmd) 的"代价账"）（过度固化）
5. **依赖单向**〔跨文件〕：skill 间依赖必须 DAG；互提候选对，人工判方向，双向依赖判违反
6. **跨 skill 指称**〔跨文件〕：单向提及（路由指针 / 题材点名）越过 skill 名指对方内部路径 / 节名 / 组名判违反，停在 skill 名或删；真实功能依赖显式保留
7. **相对路径禁止**：markdown 链接只指本 skill 目录内；跨 skill 相对链接判违反（会因对方重构无声断裂），需要时用纯文本"X 侧规范 N 节"描述
8. **参考文件禁手写目录**：参考文件内手写目录判违反；agent 全量读入不看目录，目录只对浏览器 / 编辑器有效
9. **纪律内容须有据**：纪律型 / 模式型内容无 baseline / eval 痕迹判标注"未经验证"，审计者不凭精读断言对错
10. **保留门槛**：全文每次加载都占上下文，废话零容忍。逐节逐段按 [章节](../SKILL.md#执行原则)
    的"每行自证"判（含称职 agent 本来就会做的常识规定；没把握时查溯源佐证：自体声明的动机、git blame、evals）；
    不会且非结构必需（路由 / 闸门 / 槽位）判标注"待删候选"，只标不删、用户裁定；实删转入口 2，
    有 evals 时跑回归，不回归即实证
11. **时间性信息不内联**：自身演进史（版本记录 / 修复日志）内联判违反，演进史归 git，正文最多留一句路标
12. **标点基线**：中文语境的半角 `()`、`,`、`;`、`:`、`?` 判违反，统一全角；例外口径见
    [章节](create-workflow.md#第-3-步起草-skillmd) 的"标点基线"条
