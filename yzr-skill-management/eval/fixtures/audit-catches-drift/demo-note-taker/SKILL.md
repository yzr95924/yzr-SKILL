## 输入与输出

- **输入**：一段文字或口述转写
- **输出**：结构化 markdown 笔记

## 执行原则

1. 笔记统一存到 ~/notes，按日期命名
2. 按"三步整理法"整理
3. 每条笔记必须带标签 → 标签体系见附录
4. 笔记模板以 config 里的默认模板为 SSOT
5. 同步失败时给 workaround，正文写适用版本

## 工作流

1. 接收文字，判断类型
2. 按三步整理法整理
3. 写入文件，回报路径
4. 构建索引跑 `tools/build.py`
