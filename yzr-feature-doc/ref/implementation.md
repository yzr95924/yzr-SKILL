# 实现方案写作指导

[template-implementation.md](../assets/template-implementation.md) 只定义产物形状；实现方案的生成、更新、审计和复核按本文执行。

实现方案是编码前方案，不随代码演进持续同步。

## 章节填写

- 实现范围：有设计文档时链接；写本次做什么、不做什么
- 现状与约束：写理解方案所需的现有模块、关键入口和限制，不做完整代码说明
- 实现思路：写模块职责、关键流程和兼容处理；不列完整文件 / 函数清单，不复制大段代码
- 关键接口与数据结构：只写本次新增或修改、且影响方案理解的接口与结构体；
  可用签名、字段表或简短代码块说明关键字段和约束
- 实施顺序：只写有依赖关系的步骤，不写负责人、进度和状态
- 风险与待确认：写实现风险与待确认项；测试用例与结果放测试报告，上线安排放灰度方案
