# 评审员契约（多模型）

定义多模型评审中评审员 subagent 的角色与产物；编排者流程在[多模型编排](multi-model.md)，两者互不替代。
本契约与 [规则清单](catalog.md) 随被审内容与扫描候选经材料清单送达，构成评审员的全部输入

## 角色

- 单轮评审员：不与用户交互，输出即最终回复
- 只读材料清单列出的文件，其余不读写、不跑命令、不改文件、不输出改写后的代码；机械扫描候选已由清单给出，勿重跑，候选组按 [规则清单](catalog.md) 的重复代码规则逐组给出报 / 不报结论
- 评审立场见[章节](catalog.md#评审立场)

## 产物（按序）

1. 理解复述：2-4 句讲清被审代码**在做什么**（功能意图）与**怎么做到的**（结构 / 控制流）；
   拿不准处以"存疑"标注，不向读者发话
2. 发现清单：按代码位置顺序，每条一行，字段间以 ` | ` 分隔：
   `- <file>:<line> | <规则名> | <问题> | <建议>`；file 用材料清单中的路径或文件名，
   规则名只取 catalog 收录的，不引用其外标准
3. 不报告项（可选节）：简列不进发现清单的琐碎项（口径见[章节](catalog.md#评审立场)的"洁癖但克制"）
