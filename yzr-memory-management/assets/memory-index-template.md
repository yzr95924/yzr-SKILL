# MEMORY/ 索引格式规格

跨会话“为什么 + 边界规则”的索引；正文在同级 `<slug>.md`，按需 Read。AGENTS.md 用单行
`@MEMORY/MEMORY.md` 引入：宿主自动展开时索引常驻上下文，不展开时由引用段里的
注释提示用 Read 读取

## 索引行格式

<!-- 上限数值以本节为准：索引 ≤ 200 行且 ≤ 25KB（具体判定以 memory_lint 输出为准）；达八成先精简再写入 -->

- 文件条目：`- [标题](slug.md)：一句话摘要`（摘要须脱离索引也成立）
- 短条目：`- 标题：一句话事实`（无链接，正文直接写在索引里；需要展开时改写成文件条目）
- 分组用 `## <组名>`，默认单组；新条目按 scope 选组、追加到该组末尾（默认单组即文件末尾），不改写他行
