## 字段约定

- 文件名：kebab-case（小写字母 / 数字 / 连字符），否则 lint 报 SLUG-FORMAT
- `scope`：条目约束的目录 / 文件 / 决策点；变更检查靠它匹配 git 变更，缺失 lint 报 SCOPE-MISSING

- 新鲜度：不设 modified 字段
