# AI 腔特征黑名单（ai-tells）

AI 生成文本的高频"指纹"。本文件是**黑名单**：命中即改写或删除。
诊断阶段先通读全文扫这份清单定位问题，改写阶段逐条清除。

## 中文指纹

| 指纹 | 处理 |
| --- | --- |
| "在当今快节奏的 / 瞬息万变的……时代 / 领域" 开头 | 删，从正题起笔 |
| "随着……的不断发展 / 日益普及" | 删或改成具体背景 |
| "值得注意的是 / 需要指出的是 / 众所周知" | 删，直接给内容 |
| "不言而喻 / 毋庸置疑 / 显而易见" | 删；真显然就不必说 |
| "让我们（一起）深入探讨 / 一探究竟" | 删或改成直接陈述 |
| "不仅……而且……" 双重强调 | 拆成两句，或删"不仅而且" |
| "赋能 / 抓手 / 闭环 / 链路 / 颗粒度" 等黑话堆砌 | 换成具体说法；技术专有语境保留 |
| "总的来说 / 总而言之 / 综上所述" + 全文复述 | 见 redundancy.md R4 |
| "作为……，它……" 万能开头（"作为一个 AI 助手"） | 删 |
| "的浪潮 / 的变革 / 的新篇章" 宏大叙事 | 换成具体事实 |
| "首先……其次……再次……最后……" 五段俱全 | 保留 ≤ 3 个，其余靠语序 |

## 英文指纹

| 指纹 | 处理 |
| --- | --- |
| "In today's fast-paced world" | 删 |
| "It's worth noting that / It is important to note that" | 删 |
| "delve into / embark on / navigate the landscape of" | 换成 dig into / start / handle 或直接动词 |
| "leverage / utilize" 滥用 | 换成 use（专有技术语境如 leverage a cache 保留） |
| "furthermore / moreover / additionally" 每段开头接力 | 见 style.md S8 |
| "not only … but also …" 每篇必现 | 拆句或删 |
| "In conclusion / To summarize" + 全文复述 | 见 redundancy.md R4 |
| "plays a (crucial/vital/pivotal) role in" | 换成具体作用："X handles Y" |
| "a testament to" / "a game-changer" / "the power of" | 删或换事实 |
| "Great question! / Certainly! / Absolutely!" 对话捧场 | 删 |
| "seamlessly / effortlessly / robust" 副词三连 | 见 tone.md T3 |
| 过度 hedging："It's worth mentioning that it might potentially…" | 见 tone.md T6 |

## 结构指纹（中英通用）

- **三段式总结**：正文已经说清楚，结尾再来"综上所述 / In summary"复述 → 删
- **每段加粗小标题**：连续段落都以"**重点**：" / "**Key point:**"开头 → 保留真需要的，其余去粗体
- **排比成瘾**：连续三句以上同构排比（"它是……，它是……，它是……"）→ 保留一组，
  其余改正常句式
- **列表瘾**：一句话能说清的也拆成 bullet → 合并回句子；真清单保留
- **总分总强迫**：无论什么内容都"总起—分述—总结" → 短篇删总起和总结
- **假装对话**：非对话文体里插入"你可能会问……"自问自答 → 改陈述；FAQ 文体保留

## 标点与排版指纹

- **破折号滥用**：中文"——"或英文 em-dash 每段多次、用于本可用逗号 / 句号的地方 →
  换回常规标点；强调停顿的真实需求保留
- **emoji 点缀**：技术文档 / 正式文档里段落开头 emoji（🚀💡✨）→ 删；用户原文自带且
  文体允许（个人笔记）保留
- **加粗成瘾**：每段都有加粗短语 → 只保留真正需要扫读定位的（术语定义 / 警告）
- **"首先 / 其次 / 最后"序号词** 与编号列表同时出现 → 删序号词

## 判定点

- 单个指纹出现 ≠ AI 生成，人也会写"值得注意的是"——**命中 ≥ 3 类指纹**才按"去 AI 腔"
  处理；单点命中按对应维度的规则（style / redundancy / tone）正常改写
- 黑名单是删改依据，不是禁用词表：语境需要时（引文 / 反讽 / 专有名词）保留
- 改写目标不是"检测不出来"，是"读着像作者自己写的"——别为了规避检测引入怪句
